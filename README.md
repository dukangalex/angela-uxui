# angela-uxui · Angela UX/UI 组件库

自有维护的交互组件库：480 个零依赖的 HTML/CSS/JS 交互组件，编号 001–480。

- **001–200**：界面零件（按钮、开关、输入、菜单、卡片……）
- **201–400**：网站区块与动效
- **401–480**：生产级常用件，含 AI 类（提示词输入框 #452、Agent 步骤 #454、工具执行批准 #455 等）

每个组件自带完整移植提示词（结构、交互、数据、无障碍、主题变量、完整代码、禁止事项与验收清单），可直移植进网页项目，或只取交互规格翻写成其他技术栈（如 Flutter）。

## 目录结构

- `src/elements/NNN-名称.html` — 组件源码，类名以 `.uNNN` 作用域隔离，零依赖
- `src/tokens.css` — 主题变量（`--ux-*`），明暗双主题
- `src/order.json` / `src/popular.json` — 组件排序与热门清单
- `api/v1/en/catalog.tsv` — 英文目录（编号、名称、分类）
- `api/v1/en/e/NNN.txt` — 每件组件的完整移植提示词

## 使用口径

- 取件走本地技能 local-lucian-uxui 的流程：查目录定编号 → 读源文件 → 移植进目标项目后按该项目方式自验。
- 移植时保留组件文件顶部的 MIT 署名注释行（许可证要求）。
- 本仓独立维护，与上游脱钩；上游有值得吸收的新组件时，人工挑选、审查后再收录。
